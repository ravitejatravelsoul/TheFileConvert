# Real-user product audit

**Verdict: PASS with documented LIMITED cases** — 56 scenarios · 53 PASS · 3 LIMITED · 0 FAIL

Every first-launch tool was driven the way a person uses it — through the real page of the production build (`next build && next start`), with realistic **fake** documents (no real identities or numbers) — and each downloaded output was opened by an independent program and compared with its source. The bar is the product-owner test: *would a normal user be surprised by this output?* If yes, FAIL. Limitations are listed as LIMITED or FAIL; the product was not redefined to pass. Contract: `qa/CONVERSION_SEMANTICS.md`.

## What was tested, and how

- **Fixtures** (`qa/real-user-fixtures/`, generated by `qa/scripts/real-user-fixtures.py`): 01 passport-like scan, 02 filled application, 03 certificate, 04 scanned invoice (+04b native invoice), 05 two-page bank statement scan, 06 native résumé, 07 scanned letter, 08 signed two-page contract, 09 ID-card PNG, 10 filled-form PNG, 11 receipt JPG, 12 native table report, 13 native brochure, 14 photo with text PNG, 15 native business letter DOCX, 16 complex Word report DOCX, 17 screenshot PNG, 18 table image PNG. The scans carry paper grain, tilt, handwriting-style fills, stamps, photos and signatures. `refs/` holds the native originals used only as ground truth. One real file is also used: the user's own scanned test PDF (read in place, outputs kept in git-ignored `_private/`).
- **Harness**: `qa/scripts/rup-audit.mjs` (Playwright, Chromium desktop and Pixel 7 emulation) → downloads through the page's own buttons → `qa/validate/visdiff.py` (SSIM over 8×8 blocks of a 100-dpi render, PSNR, changed-pixel share, page sizes, text recall), `docxinfo.py` (sections, page sizes, text characters, pictures, embedded media, bytes) and `layoutdiff.py` (word positions, reading order) — all independent of the product. Source | output | difference images are in `qa/fidelity/real-user/`.
- **`.docx` renderer**: LibreOffice 26.2.6 (QA only). Microsoft Word is installed but unlicensed and its automation hangs, so **no `.docx` verdict is a claim about Word — manual Word review is required** (`qa/manual-word-review/`). For full-page pictures LibreOffice places the image up to 1 px (0.7 pt) off; the comparison forgives ±1 px (`--align 1`, reported as `alignedBy`).
- **Thresholds**: scans kept visually — render SSIM ≥ 0.95 PASS / ≥ 0.90 LIMITED, one picture per page, no text layer, ≥ 140 dpi, ≤ 1.2 MB per page; native pages — text recall ≥ 98 %, reading order ≥ 80 %, tables and pictures kept, SSIM ≥ 0.80; Image → Word — media bytes identical to the source, page shape, render SSIM ≥ 0.85; page operations — identical (SSIM ≥ 0.999); editor — ≤ 0.05 % pixels changed outside the edit; OCR — searchable ≥ 90 % of the document's words, pixels unchanged.
- **Privacy / network**: every run also records requests; none carries a body or leaves the origin.

- **LIMITED** — Word → PDF: DOCUMENT-16-complex-word-report.docx — look=LIMITED — All text, the table, chart and footer are there; LIMITED because line spacing and the bullet glyph differ by a few points from LibreOffice's own rendering, and Word's own layout may differ again.

## Fixed during this audit

- **Scanned documents became retyped text (the semantics mistake)** — The default for a scanned page is now the page itself as a picture, classified per page (`classify.ts`); hybrid editable text only when the reading is extremely reliable.
- **A scan written as a 3 MB PNG** — A faint-noise scan counted as 'few colours' and was stored as PNG: 3.39 MB DOCX for an 856 KB PDF. Now the smaller of JPEG/PNG is used: 0.85 MB; the user's scan 3.89 MB → 0.33 MB.
- **Native brochure spilled a call-out onto a second page** — A few points of line-height drift pushed a shaded block past the bottom margin; the margin slack is now 20 pt.
- **Console error from the OCR engine** — Tesseract printed "Estimating resolution as N"; the real render density is now passed to it. OCR accuracy unchanged.
- **Editor: correcting text on a dark band drew black on a white box** — A résumé's white-on-dark name line became a white rectangle with black text. The correction now covers with the page's own background colour and writes in the line's own colour.
- **Poster-size scans** — A scan's page picture is capped at 5000 px on its long side so a huge page cannot exceed canvas limits.
