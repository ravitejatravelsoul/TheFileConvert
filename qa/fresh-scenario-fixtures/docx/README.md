# Word → PDF fixtures

Generated by `python qa/scripts/fs-docx-fixtures.py` (python-docx, Pillow, msoffcrypto-tool) — real Word
packages written by libraries that have nothing to do with our converter. The .docx files are regenerated,
not committed; `truth.json` (text in reading order + what each PDF must show) is committed. A small subset
lives in `e2e/fixtures/docx/` for the unit and Playwright tests.
